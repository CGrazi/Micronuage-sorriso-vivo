# Sorriso Vivo

Site criado no Micronuage.

## Como rodar

```bash
npm install
npm run dev
```

- `npm run build` — gera a versão de produção
- `npm test` — roda os testes

Feito com: React, Vite, TypeScript, Tailwind CSS, React Router.

## Pedido original

O que foi pedido quando o site foi criado na Micronuage:

> Crie um site para uma clínica odontológica chamada "Sorriso Vivo", em São Paulo. Deve apresentar a clínica, listar os serviços e ter um formulário de contato para agendar consulta. Visual moderno e profissional.
